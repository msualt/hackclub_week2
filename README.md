This is the submission for the week 2 project on Hackclub. This project is supposed to be a prop ballistics shield, being around 1200mmx600mm with around 25mm of thickness. While it will definitely not be stopping anything, I think it would be interesting to try to print something of this scale, and to see if it works. In the interior, I have placed channels to route steel rods through to give it a skeleton, hopefully making it easier to align when gluing and hold it's shape. Since it is so large, I think it is split into 17 main pieces, with handles on the side.
